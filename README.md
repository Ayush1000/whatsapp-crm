# WhatsApp CRM

A scalable, microservices-based CRM platform for clinics and healthcare businesses.

## Services

| Service | Responsibility |
|---|---|
| Patient Service | Patient registration and management |
| Appointment Service | Appointment booking, rescheduling and cancellation |
| WhatsApp Service | WhatsApp communication and messaging |
| Notification Service | SMS, WhatsApp and other notifications |
| Payment Service | Payment processing |
| Medical Record Service | Medical reports and documents |
| Prescription Service | Patient prescriptions |

## Technology

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Apache Kafka
- Docker
- Kubernetes
- REST APIs
